# 道具贪吃蛇 · Item Snake

在经典贪吃蛇上引入 **6 种道具/特殊食物** 的策略玩法（课程设计加分项）。
纯 HTML + 原生 JS + Canvas，**零依赖、零构建、3 个请求**。

## 玩法

| 道具 | 颜色 | 效果 |
|---|---|---|
| 🍎 普通苹果 | 红 | +1 分、蛇 +1 长（吃掉立即补位） |
| 🐢 减速食物 | 蓝 | 速度 ×0.55，持续 5s |
| 🚀 加速食物 | 橙 | 速度 ×1.70，持续 5s |
| ✂ 减身食物 | 紫 | 立即缩短 3 节（下限 3） |
| ☠ 毒药 | 黑绿 | **吃到立即游戏结束** |
| ✨ 双倍分数 | 粉 | 得分 ×2，持续 8s |

- **操作**：方向键 / WASD / 触屏滑动；空格暂停，R 重开
- **生成**：场上始终 1 个苹果；特殊道具每 2.6s 至多生成 1 个、同时最多 4 个、存活 13s
- **速度**：基础 140ms/格 → 26 节封顶 70ms/格，道具在其基础上乘除
- **死亡**：撞墙 / 撞自身 / 吃毒药，结算时会标注死因

## 运行

直接双击 `index.html`，或：

```
cd snake-items
python -m http.server 8000   # 可选
```

调试预览：`index.html?demo=1`（预置全部 6 种道具与激活效果）。

## 测试

## 与 Snake.io 的关系

借鉴其道具博弈与霓虹观感；保留**网格步进**（而非连续蛇形运动），
以复用已验证的确定性逻辑与帧插值，降低实现与测试复杂度（详见 PRD §11）。
